# Instruções para o Claude Code

Este projeto utiliza o protocolo **ShareBrain** para persistência de contexto multi-agente.

> **⚠️ REGRA OBRIGATÓRIA:** Siga rigorosamente todas as diretrizes descritas no arquivo **`ShareBrain.md`** localizado na raiz deste repositório antes de iniciar qualquer tarefa ou concluir sua sessão.

- **Estado Atual:** Leia `.ai-workspace/state.json`
- **Histórico:** Leia `.ai-workspace/history.jsonl`
- **Decisões:** Consulte `.ai-workspace/decisions.md`
